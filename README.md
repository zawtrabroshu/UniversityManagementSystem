# Система управління навчальним процесом університету

Цей проєкт був створений у межах індивідуального навчального завдання. Його основна мета - розробити програму для управління навчальним процесом університету.

За допомогою системи можна працювати зі студентами, викладачами, предметами, оцінками та кафедрами, а також переглядати різні навчальні звіти.

## Основні можливості

- Додавання, редагування та видалення студентів і викладачів.
- Управління навчальними предметами.
- Додавання та редагування оцінок студентів.
- Переведення числових оцінок у літерну систему.
- Перегляд середнього балу студента.
- Формування академічної виписки студента.
- Перегляд статистики кафедр та навчальних груп.
- Створення PDF-звітів.
- Авторизація користувачів через API.
- Розподіл прав доступу залежно від ролі користувача.

## Ролі користувачів

У програмі передбачено чотири основні ролі:

- **Admin** - має доступ до всіх функцій системи.
- **Student** - може переглядати власні оцінки та академічну виписку.
- **Teacher** - може працювати зі своїми предметами та виставляти оцінки.
- **Department Head** - може переглядати статистику та звіти кафедри.

## Структура проєкту

Проєкт складається з чотирьох основних частин:

- **University.Domain** - містить основні класи та сутності системи.
- **University.BusinessLogic** - відповідає за логіку роботи програми та обробку даних.
- **University.Persistence** - відповідає за збереження та отримання даних.
- **University.Presentation** - містить консольне меню та взаємодію з користувачем.

## Використані технології

- C#
- .NET 8
- Entity Framework Core
- SQLite
- REST API
- JWT
- QuestPDF
- Git та GitHub

## Як запустити проєкт

1. Завантажити репозиторій:

```bash
git clone https://github.com/zawtrabroshu/UniversityManagementSystem.git
```

2. Відкрити файл `UniversityManagementSystem.sln` у Visual Studio 2022.

3. Дочекатися відновлення NuGet-пакетів.

4. Перевірити налаштування підключення до API.

5. Запустити проєкт `University.Presentation`.

## База даних

Для збереження даних використовується SQLite, а для роботи з базою даних - Entity Framework Core.

## Про проєкт

Проєкт розроблений самостійно в навчальних цілях для закріплення знань із C#, об'єктно-орієнтованого програмування, роботи з базами даних, API та системами контролю версій.
